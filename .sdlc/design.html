Customer Support Bot

Design view for the implemented local Streamlit MVP. The service checks customer memory before starting AutoGen; each specialist searches SerpAPI before answering. Triage returns plain text for clarification or off-topic replies (both use source clarify); it does not hand off to a user agent. The Swarm stops on the first agent text message or at ten messages. The separate UI human-ticket action uses source human. See design.md for contracts, risks, and test evidence.

Implemented evidence: 25 tests passed and two live tests were skipped because provider keys were unavailable. The Streamlit UI was smoke-checked in a browser with dummy keys. This does not verify live OpenAI or SerpAPI behavior.

Failure boundary: provider and local-file errors return an explicit failure or escalation state. Customer files and tickets stay local; credentials are loaded from environment configuration.
